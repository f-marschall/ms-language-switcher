# Microsoft Learn English

Because learning Azure is hard enough without having to reverse-engineer the German translation.

Ever opened Microsoft Learn, read a translated technical term, and wondered whether Microsoft had released an entirely new Azure service?

You came here to learn about Availability Zones, not to figure out what a *Verfügbarkeitszone* is.

This extension automatically redirects localized Microsoft Learn pages to English (`en-us`). No language selector, no manual URL editing, no additional suffering.

## Features

- Automatically redirects localized Microsoft Learn URLs to English.
- Preserves the article path and query parameters.
- No tracking, dependencies or background service worker.
- Does one thing. Unlike Azure, it does not need its own certification.

## Installation

1. Clone or download this repository.
2. Open `edge://extensions/` or `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the repository folder.
5. Open a [German Microsoft Learn article](https://learn.microsoft.com/de-de/azure/storage/common/storage-redundancy) and enjoy the original terminology.

## Privacy

No data collection. See [Privacy Policy](PRIVACY.md).

English URLs and URLs without a locale are left unchanged.

This independent extension is not affiliated with Microsoft. No translators were harmed in its development.
