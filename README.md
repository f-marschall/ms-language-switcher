# Microsoft Learn English

**Microsoft Learn is great. Its translations are not.**

Automatically redirects Microsoft Learn pages to English (`en-us`). No configuration, no tracking.

## Installation (Microsoft Edge)

1. [Download the ZIP](https://github.com/f-marschall/ms-language-switcher/archive/refs/heads/main.zip) and extract it.
2. Open `edge://extensions/` in Microsoft Edge.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.

That's it. Enjoy Microsoft Learn in English.
