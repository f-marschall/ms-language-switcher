# Microsoft Learn English

Automatically redirects localized Microsoft Learn pages to English (en-US).

## Installation

1. Clone or download this repository.
2. Open `edge://extensions/` (or `chrome://extensions/`).
3. Enable Developer mode.
4. Click Load unpacked and select the repository folder.
5. Visit https://learn.microsoft.com/de-de/azure/storage/common/storage-redundancy to test.

The extension redirects localized HTTPS Microsoft Learn top-level navigations to en-us, retaining the remaining URL. English URLs are exempt. URLs without a locale are unchanged. No background worker or analytics is included.

This independent extension is not affiliated with Microsoft.
